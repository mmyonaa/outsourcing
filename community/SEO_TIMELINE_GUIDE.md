## 🚀 빠른 노출 방법 (시간 단축)

### 방법 1: URL 수동 색인 요청 ⭐ 추천

#### Google
1. [Google Search Console](https://search.google.com/search-console) 접속
2. 상단 검색창에 URL 입력:
   ```
   http://bktheater.com/
   http://bktheater.com/introduce
   http://bktheater.com/performance
   http://bktheater.com/rental
   http://bktheater.com/notice
   ```
3. **"색인 생성 요청"** 클릭

**효과:** 24-48시간 내 색인

#### Naver
1. [네이버 서치어드바이저](https://searchadvisor.naver.com/) 접속
2. **"요청" → "URL 수집 요청"**
3. URL 입력 (하루 10개 제한):
   ```
   http://bktheater.com/
   http://bktheater.com/introduce
   http://bktheater.com/performance
   http://bktheater.com/rental
   http://bktheater.com/notice
   ```

**효과:** 1-3일 내 수집

## 💡 자주 묻는 질문 (FAQ)

### Q1: 언제쯤 검색 결과에 나타나나요?
**A:** 평균 **1-2주** 후 "보광극장" 검색 시 나타납니다.

### Q2: 더 빠르게 할 수 있나요?
**A:** 네! **네이버 플레이스**를 등록하면 **1-3일** 내 최상단 노출됩니다.

### Q3: "site:bktheater.com"에서 나타나는데 "보광극장"으로는 안 나와요.
**A:** 정상입니다. 색인은 되었지만 순위가 아직 낮은 상태입니다. 1-2주 더 기다리면 나타납니다.

### Q4: 순위가 계속 바뀌어요.
**A:** 정상입니다. 처음 1개월은 순위가 불안정합니다. 점차 안정화됩니다.

### Q5: 경쟁사보다 순위가 낮아요.
**A:** 다음을 확인하세요:
- 사이트 운영 기간 (오래된 사이트가 유리)
- 콘텐츠 양 (많을수록 유리)
- 백링크 수 (많을수록 유리)
- 업데이트 빈도 (자주 할수록 유리)

### Q6: 아무것도 안 보여요.
**A:** 다음을 확인하세요:
1. 배포가 제대로 되었는지
2. sitemap.xml이 접근 가능한지
3. robots.txt가 차단하고 있지 않은지
4. Google/Naver에서 소유권 확인이 완료되었는지
