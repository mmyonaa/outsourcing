# 네이버 서치어드바이저 등록 가이드

## 1. 접속 및 로그인

1. [네이버 서치어드바이저](https://searchadvisor.naver.com) 접속
2. 네이버 계정으로 로그인
3. 상단의 **"웹마스터 도구"** 클릭

---

## 2. 사이트 선택

1. 사이트 목록에서 `http://bktheater.com` 클릭

---

## 3. 사이트맵 제출

1. 왼쪽 메뉴에서 **"요청"** 클릭
2. **"사이트맵 제출"** 클릭
3. 입력창에 `https://bktheater.com/sitemap.xml` 입력
4. **"확인"** 클릭

---

## 4. 페이지 수집 요청

1. 왼쪽 메뉴 **"요청"** → **"웹 페이지 수집"** 클릭
2. 아래 주소들을 하나씩 입력하고 **"확인"** 클릭:

```
https://bktheater.com/
https://bktheater.com/introduce
https://bktheater.com/performance
https://bktheater.com/rental
https://bktheater.com/notice
https://bktheater.com/news
```

---

## 5. 확인 (며칠 후)

- 왼쪽 메뉴 **"리포트"** → **"사이트 현황"** 에서 등록된 페이지 수 확인
