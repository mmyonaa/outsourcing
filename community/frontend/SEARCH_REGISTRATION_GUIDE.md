# 검색 엔진 등록 가이드

## 🚀 빠른 시작 체크리스트

### 배포 후 즉시 해야 할 일

#### 1. Google Search Console 등록
1. [Google Search Console](https://search.google.com/search-console) 접속
2. "속성 추가" 클릭
3. URL 접두어 방식 선택 → 실제 도메인 입력
4. HTML 태그 방식으로 확인 (이미 index.html에 추가됨)
5. **Sitemap 제출**:
   - 왼쪽 메뉴 "Sitemaps" 클릭
   - `https://your-domain.com/sitemap.xml` 입력
   - "제출" 클릭
6. **URL 검사**:
   - 상단 검색창에 홈페이지 URL 입력
   - "색인 생성 요청" 클릭
   - 주요 페이지 5-10개도 같은 방식으로 요청

#### 2. Naver 서치어드바이저 등록
1. [네이버 서치어드바이저](https://searchadvisor.naver.com/) 접속
2. 사이트 등록
3. 소유권 확인 (HTML 태그 방식)
4. 사이트맵 제출
5. 수집 요청

#### 3. Daum(Kakao) 검색 등록
1. [Daum 검색등록](https://register.search.daum.net/index.daum) 접속
2. 사이트 등록 신청

## ⏱️ 검색 결과에 나타나는 시기

- **첫 색인**: 1-3일 (빠르면 몇 시간)
- **"보광극장" 검색 시 상위 노출**: 2주~3개월
  - 경쟁이 적으면 빠름
  - 사이트 이름 "보광극장"이면 브랜드 검색은 비교적 빠름

### 즉시 확인하는 방법
- **브랜드명으로 검색**: `"보광극장" site:your-domain.com`
- Google Search Console에서 색인 상태 확인
