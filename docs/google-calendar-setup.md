# 구글 캘린더 설정 가이드

RentalSchedule.vue 페이지에 구글 캘린더를 연동하는 방법을 안내합니다.

> 📌 **이 문서는 두 부분으로 구성되어 있습니다:**
> - **1~5번**: 개발자 또는 초기 설정 담당자용 (최초 1회만 수행)
> - **6번 이후**: 일상적인 일정 관리자용 (자주 참고)

## 1. 구글 캘린더 생성 (이미 있다면 3번으로 이동)

1. [Google Calendar](https://calendar.google.com) 접속
2. 좌측 사이드바에서 **"다른 캘린더" 옆 + 버튼** 클릭
3. **"새 캘린더 만들기"** 선택
4. 캘린더 정보 입력:
   - **이름**: 극단 BK 대관 스케줄
   - **설명**: 극단 BK 대관 일정 관리
   - **시간대**: 대한민국 표준시 (GMT+09:00)
5. **"캘린더 만들기"** 클릭

---

## 2. 캘린더 공개 설정

1. 좌측 사이드바에서 생성한 캘린더 위에 마우스를 올려놓고 **⋮ (점 3개)** 클릭
2. **"설정 및 공유"** 선택
3. **"액세스 권한"** 섹션에서:
   - ✅ **"공개 사용 설정"** 체크박스 체크
   - 경고 메시지가 나오면 **"확인"** 클릭
4. 공개 범위 선택:
   - **"모든 일정 세부정보 보기"** 또는 **"약속있음/없음 정보만 보기"** 선택
   - 권장: **"모든 일정 세부정보 보기"** (대관 정보를 상세히 보여주기 위해)

---

## 3. 캘린더 ID 확인

1. 여전히 "설정 및 공유" 페이지에서 아래로 스크롤
2. **"캘린더 통합"** 섹션 찾기
3. **"캘린더 ID"** 복사
   - 형식: `xxxxxxxxxxxxxxxx@group.calendar.google.com`
   - 예시: `abc123xyz@group.calendar.google.com`

---

## 4. 임베드 코드 생성 (선택사항 - 더 세밀한 설정)

임베드 코드를 커스터마이징하려면:

1. "설정 및 공유" 페이지에서 **"캘린더 통합"** 섹션
2. **"맞춤설정" 버튼** 클릭
3. 원하는 옵션 선택:
   - 제목 표시 여부
   - 탐색 버튼 표시
   - 날짜 표시
   - 인쇄 아이콘 표시
   - 시간대
   - 기본 뷰 (월/주/일/일정)
4. 생성된 iframe 코드 복사

## 5. 코드에 캘린더 ID 적용

### 방법 A: 기본 설정 사용 (권장)

`RentalSchedule.vue` 파일의 **29번째 줄**에서 `YOUR_CALENDAR_ID` 부분을 3번에서 복사한 캘린더 ID로 교체:

```vue
<iframe
  src="https://calendar.google.com/calendar/embed?height=600&wkst=1&bgcolor=%23ffffff&ctz=Asia%2FSeoul&showTitle=0&showNav=1&showDate=1&showPrint=0&showTabs=1&showCalendars=0&mode=MONTH&hl=ko&src=YOUR_CALENDAR_ID%40group.calendar.google.com"
  ...
/>
```

**변경 예시:**
```
src="...&src=abc123xyz%40group.calendar.google.com"
```

### 방법 B: 커스텀 임베드 코드 사용

4번에서 생성한 임베드 코드를 그대로 붙여넣기:

1. `RentalSchedule.vue` 파일 열기
2. 28~35번째 줄의 `<iframe>` 태그 전체를 4번에서 복사한 코드로 교체
3. `style`, `width`, `height` 속성은 유지 권장:
   ```html
   style="border:solid 1px #777"
   width="100%"
   height="600"
   ```

## 6. 일정 등록 방법 (관리자용)

### 🎯 일상적인 일정 등록 - 빠른 가이드

**개발자가 아닌 관리자분들을 위한 간단한 가이드입니다.**

#### 방법 1: 날짜 클릭으로 빠르게 등록하기

1. **구글 캘린더 접속**
   - 웹 브라우저(크롬, 엣지 등)를 열고 https://calendar.google.com 에 접속
   - 로그인이 안 되어 있다면 구글 계정으로 로그인

2. **내 캘린더 목록에서 "극단 BK 대관 스케줄" 찾기**
   - 화면 왼쪽에 "내 캘린더" 목록이 있습니다
   - "극단 BK 대관 스케줄" 옆 체크박스가 체크되어 있는지 확인
   - 체크되어 있지 않으면 클릭해서 활성화

3. **대관 일정 등록하기**
   - 캘린더에서 원하는 날짜를 **한 번** 클릭 (하루 종일 일정)
   - 또는 시작 시간 부분을 클릭한 후 아래로 드래그해서 종료 시간까지 선택 (시간 지정 일정)

4. **일정 정보 입력창이 나타납니다**
   - **제목 입력란**: 예시 입력
     - "극단 OO 대관"
     - "○○○ 연극 연습 - 대관"
     - "△△ 행사 대관"
   - **날짜/시간 확인**: 자동으로 선택한 시간이 입력되어 있습니다
     - 잘못 선택했다면 날짜/시간 부분을 클릭해서 수정 가능

5. **캘린더 선택 (중요!)**
   - 입력창에서 캘린더 이름이 표시된 부분을 클릭
   - 드롭다운 메뉴에서 **"극단 BK 대관 스케줄"** 선택
   - ⚠️ 다른 캘린더를 선택하면 웹사이트에 표시되지 않습니다!

6. **추가 정보 입력 (선택사항)**
   - "설명 추가" 또는 "메모 추가"를 클릭하면 상세 정보 입력 가능
   - 예: "대관자: 홍길동, 연락처: 010-1234-5678, 대관료: 결제 완료"

7. **저장하기**
   - 파란색 **"저장"** 버튼 클릭
   - 잠시 후 웹사이트 대관 스케줄 페이지에서 확인 가능

#### 방법 2: 상세 정보와 함께 등록하기

더 자세한 정보를 입력하고 싶다면:

1. 위 방법대로 일정 입력창을 연 후
2. **"추가 옵션"** 또는 **"더 많은 옵션"** 클릭
3. 상세 입력 페이지가 열립니다:
   - **제목**: 대관 정보 입력
   - **날짜 및 시간**:
     - 하루 종일: "하루 종일" 체크박스 선택
     - 특정 시간: 시작/종료 시간 선택
   - **반복**: 매주 반복되는 대관이라면 설정 가능 (예: 매주 수요일)
   - **캘린더**: "극단 BK 대관 스케줄" 선택 (필수!)
   - **설명**: 대관 상세 내용, 연락처, 특이사항 등
   - **위치**: 필요시 장소 정보 입력
4. 우측 상단 **"저장"** 버튼 클릭

### 📝 일정 수정하기

1. 캘린더에서 수정하고 싶은 일정을 **클릭**
2. 팝업창에서 **연필 아이콘(✏️)** 또는 **"수정"** 클릭
3. 내용을 수정한 후 **"저장"** 클릭

**빠른 시간 변경:**
- 일정을 클릭한 상태로 **드래그**하면 날짜/시간을 빠르게 이동할 수 있습니다

### 🗑️ 일정 삭제하기

1. 삭제하려는 일정을 **클릭**
2. 팝업창에서 **휴지통 아이콘(🗑️)** 또는 **"삭제"** 클릭
3. 확인 메시지가 나오면 **"삭제"** 다시 클릭

### ⚠️ 중요한 주의사항

1. **일정을 등록/수정/삭제하면 웹사이트에 즉시 반영됩니다**
   - 저장 버튼을 누른 직후부터 모든 방문자가 볼 수 있습니다
   - 테스트로 등록한 일정은 반드시 삭제해주세요

2. **올바른 캘린더 선택하기**
   - 반드시 "극단 BK 대관 스케줄" 캘린더에 등록해야 웹사이트에 표시됩니다
   - 개인 캘린더나 다른 캘린더에 등록하면 표시되지 않습니다

3. **인터넷 연결 필요**
   - 구글 캘린더는 인터넷이 연결된 상태에서만 사용 가능합니다

### 💡 실무 활용 팁

**색상으로 일정 구분하기:**
1. 등록된 일정을 클릭
2. 색상 팔레트 아이콘 클릭
3. 원하는 색상 선택
   - 예: 공연 대관은 빨강, 연습 대관은 파랑, 행사는 초록 등

**반복 일정 설정하기:**
- 매주 같은 요일/시간에 대관이 있다면 "반복" 옵션 활용
- 예: 매주 수요일 저녁 7시~10시 연습 대관

**알림 설정하기:**
- 일정 입력 시 "알림 추가"로 대관 전 미리 알림 받기
- 예: 대관 1일 전 알림 설정

### 📱 스마트폰에서 관리하기

1. **구글 캘린더 앱 설치**
   - iOS: App Store에서 "Google Calendar" 검색 후 설치
   - Android: Play 스토어에서 "Google Calendar" 검색 후 설치

2. **앱에서 일정 등록/수정**
   - 앱을 열고 동일한 구글 계정으로 로그인
   - 우측 하단 **+ 버튼** 눌러서 일정 추가
   - 나머지 과정은 웹 버전과 동일

3. **이동 중에도 일정 관리 가능**
   - 외출 중에도 스마트폰으로 빠르게 일정 추가/수정 가능

## 7. 권한 관리 (여러 명이 함께 관리하기)

### 다른 사람에게 관리 권한 부여하기

여러 명이 캘린더를 함께 관리해야 하는 경우 (예: 대관 담당 직원 여러 명):

**권한을 부여하는 방법:**

1. **구글 캘린더 웹사이트 접속**
   - https://calendar.google.com 에서 로그인

2. **캘린더 설정 열기**
   - 좌측 사이드바에서 "극단 BK 대관 스케줄" 위에 마우스 올리기
   - 나타나는 **⋮ (점 3개)** 아이콘 클릭
   - **"설정 및 공유"** 선택

3. **사용자 추가**
   - 페이지를 아래로 스크롤해서 **"특정 사용자와 공유"** 섹션 찾기
   - **"사용자 추가"** 버튼 클릭

4. **이메일 입력 및 권한 선택**
   - 관리자로 추가할 사람의 **구글(Gmail) 이메일 주소** 입력
   - 권한 레벨 선택:
     - 🟢 **"일정 변경"** (권장): 일정 추가/수정/삭제만 가능
     - 🟡 **"일정 변경 및 공유 관리"**: 모든 권한 (다른 사람에게도 권한 부여 가능)
     - 🔵 **"약속있음/없음 정보만 보기"**: 읽기 전용
     - 🔵 **"모든 일정 세부정보 보기"**: 읽기 전용 (상세정보 포함)

5. **전송**
   - **"전송"** 버튼 클릭
   - 상대방의 이메일로 초대장이 발송됩니다

6. **초대받은 사람이 할 일**
   - 이메일을 확인하고 초대 수락
   - 구글 캘린더에 접속하면 좌측 "내 캘린더"에 "극단 BK 대관 스케줄"이 표시됩니다
   - 이제 부여받은 권한에 따라 일정 관리 가능

### 💡 권한 관리 팁

**권장 권한 설정:**
- **대관 담당 직원**: "일정 변경" 권한
- **팀장/관리자**: "일정 변경 및 공유 관리" 권한
- **열람만 필요한 직원**: "모든 일정 세부정보 보기" 권한

**권한 수정 또는 제거:**
1. "설정 및 공유" > "특정 사용자와 공유" 섹션
2. 수정하려는 사용자 옆 **X** 버튼 클릭 (삭제)
3. 또는 사용자 이름 클릭 후 권한 레벨 변경

## 문제 해결

### 😕 자주 묻는 질문 (FAQ)

#### Q1. 일정을 등록했는데 웹사이트에 안 보여요

**해결 방법:**
1. **올바른 캘린더에 등록했는지 확인**
   - 구글 캘린더에서 등록한 일정을 클릭
   - 어느 캘린더에 속해있는지 확인 (일정 상세 페이지에서 캘린더 이름 확인)
   - "극단 BK 대관 스케줄"이 아니면 일정을 수정해서 올바른 캘린더로 이동

2. **웹사이트 페이지 새로고침**
   - 브라우저에서 F5 키를 누르거나 새로고침 버튼 클릭
   - 구글 캘린더 반영까지 1~2분 정도 걸릴 수 있습니다

3. **캘린더가 공개로 설정되어 있는지 확인**
   - 구글 캘린더 > 좌측 사이드바 > "극단 BK 대관 스케줄" 옆 ⋮ 클릭
   - "설정 및 공유" 선택
   - "공개 사용 설정" 체크박스가 체크되어 있는지 확인

#### Q2. 일정을 삭제했는데 웹사이트에 계속 보여요

**해결 방법:**
1. 웹사이트에서 Ctrl + F5 (강력 새로고침) 시도
2. 브라우저 캐시 문제일 수 있으니 다른 브라우저나 시크릿 모드에서 확인
3. 구글 캘린더에서 해당 일정이 정말 삭제되었는지 재확인

#### Q3. 실수로 일정을 삭제했어요, 복구할 수 있나요?

**해결 방법:**
1. 구글 캘린더 웹사이트 접속
2. 좌측 사이드바에서 **휴지통** 아이콘 또는 **"휴지통"** 메뉴 클릭
3. 삭제된 일정 목록에서 복구하려는 일정 찾기
4. 일정을 클릭하고 **"복원"** 버튼 클릭
5. ⚠️ 30일이 지난 일정은 영구 삭제되어 복구 불가능합니다

#### Q4. 여러 명이 동시에 일정을 관리해도 되나요?

**답변:**
- 네, 가능합니다!
- 관리자를 추가하려면 "7. 권한 관리" 섹션을 참고하세요
- 여러 명이 동시에 수정할 수 있으며, 변경 사항은 실시간으로 반영됩니다

#### Q5. 스마트폰에서도 일정을 추가/수정할 수 있나요?

**답변:**
- 네, 구글 캘린더 앱을 설치하면 모바일에서도 관리 가능합니다
- 위 "📱 스마트폰에서 관리하기" 섹션 참고

#### Q6. 일정에 첨부파일을 추가할 수 있나요?

**답변:**
- 네, 가능합니다
- 일정 수정 페이지(추가 옵션)에서 "첨부파일 추가" 클릭
- Google Drive 파일 또는 컴퓨터에서 파일 업로드 가능
- ⚠️ 첨부파일은 웹사이트 캘린더에는 표시되지 않고, 구글 캘린더에서만 확인 가능합니다

#### Q7. 과거 날짜의 일정도 등록할 수 있나요?

**답변:**
- 네, 과거 일정도 등록 가능합니다 (기록 목적 등)
- 과거 날짜를 선택해서 동일한 방법으로 등록하면 됩니다

### 🔧 기술적인 문제 해결 (개발자용)

#### 캘린더가 보이지 않는 경우

1. **캘린더 ID 확인**:
   - `@group.calendar.google.com` 형식이 맞는지 확인
   - URL에서 `%40`로 인코딩되었는지 확인 (`@` → `%40`)

2. **공개 설정 확인**:
   - 구글 캘린더 "설정 및 공유"에서 "공개 사용 설정" 체크 확인

3. **브라우저 캐시 삭제**:
   - Ctrl + F5 (강력 새로고침)

4. **iframe 차단 확인**:
   - 브라우저 확장 프로그램(광고 차단기 등)이 iframe을 차단하는지 확인

#### 일정이 업데이트되지 않는 경우

- 구글 캘린더 측에서 약간의 지연이 있을 수 있습니다 (보통 1~2분)
- 페이지를 새로고침해보세요

## 추가 커스터마이징

### URL 파라미터 설명

iframe의 `src` URL에서 다음 파라미터를 조정할 수 있습니다:

- `height=600`: 캘린더 높이
- `wkst=1`: 주 시작 요일 (1=월요일, 2=일요일)
- `bgcolor=%23ffffff`: 배경색 (#ffffff → %23ffffff)
- `ctz=Asia%2FSeoul`: 시간대
- `showTitle=0`: 제목 표시 (0=숨김, 1=표시)
- `showNav=1`: 탐색 버튼 표시
- `showDate=1`: 날짜 표시
- `showPrint=0`: 인쇄 아이콘 표시
- `showTabs=1`: 탭 표시
- `showCalendars=0`: 캘린더 목록 표시
- `mode=MONTH`: 기본 뷰 (MONTH/WEEK/AGENDA)
- `hl=ko`: 언어 (ko=한국어)

### ✅ 일정 등록 체크리스트

일정을 등록할 때 이것만 확인하세요:

1. ✅ 구글 캘린더(calendar.google.com) 접속
2. ✅ 좌측에서 "극단 BK 대관 스케줄" 캘린더 확인
3. ✅ 날짜/시간 선택 (클릭 또는 드래그)
4. ✅ 제목 입력 (예: "극단 OO 대관")
5. ✅ **캘린더 선택 = "극단 BK 대관 스케줄"** ⚠️ 중요!
6. ✅ 저장 버튼 클릭
7. ✅ 웹사이트에서 확인 (1~2분 후)

### 🔑 핵심 포인트

- **웹사이트에 표시되려면**: 반드시 "극단 BK 대관 스케줄" 캘린더에 등록
- **즉시 반영**: 저장하면 1~2분 내에 웹사이트에 자동으로 표시됨
- **복구 가능**: 실수로 삭제해도 30일 내 휴지통에서 복구 가능
- **어디서나 관리**: PC, 스마트폰, 태블릿 모두 사용 가능
